## Sales Performance Dashboard

## OVERVIEW:
An Excel project analysing sales performance and presenting key findings through an interactive dashboard.

## TOOLS & TECHNIQUES: 
-Excel & Power Query – data cleaning and preparation

-Data Model & Relationships – connecting related datasets

-PivotTables – analysing sales performance

-PivotCharts – visualising key metrics and trends

-Dashboard – presenting insights in an interactive format

## PROCESS: 
The raw data was cleaned and transformed using Power Query, with relevant tables connected through relationships in the Data Model. PivotTables were then used to analyse sales performance, while PivotCharts converted the results into visual insights. These elements were combined to create the final sales performance dashboard.ance using PivotTables, and transformed the results into a dashboard for clear visual representation.

## KEY INSIGHTS:
The dashboard highlights key sales performance trends, including sales by product, category, region, and other relevant performance indicators.
